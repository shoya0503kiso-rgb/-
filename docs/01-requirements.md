## 不足していた仕様（洗い出し結果）

元要件だけでは実装時に決められなかった点。すべて暫定仕様として決めて先に進める。

1. **営業日の区切り**：深夜営業の場合、0時を跨いだ勤務をどの日付に帰属させるか → P-04
2. **営業時間**の具体値（異常チェックの基準） → P-05
3. **iPad打刻の本人確認**（名前をタップするだけか、PINを入れるか） → P-06
4. **退勤のみの打刻**を受け付けるか（拒否するとその日の勤務記録が取れない） → P-07
5. **休憩の回数**（1回か複数回か） → P-08
6. **時間の丸め**（1分単位か15分単位か） → P-09
7. 「長すぎる」「営業時間から大きく外れる」の**閾値** → P-10
8. 「休憩不足」の**一般基準**（休日ルール以外） → P-11
9. 「**休日**」の定義（土日祝？店休日？本人の公休？）と「7時間以上」が実働か拘束か → P-12
10. **修正の権限と理由**の要否 → P-13
11. 要確認勤怠を**確認済み**にして件数から消す操作 → P-14
12. **PDF出力**の方式 → P-15
13. **管理者の権限分け**（店長とシフト担当で違うか） → P-16
14. **LINEアカウントと従業員の紐付け方法**、シフト提出の画面方式 → P-17
15. **シフトの形**（時間帯の枠があるのか、自由な時間か）と希望の入力粒度 → P-18
16. 通知・締切の**正確な日時**と、未提出日の扱い → P-19
17. **締切後の提出・変更**の扱い → P-20
18. **確定後の変更**と再通知 → P-21
19. 最大・最低勤務日数が**絶対条件か希望条件か** → P-22
20. 相性条件の**強さ** → P-23
21. **遅刻の定義**（猶予時間） → P-24
22. **連勤上限** → P-25
23. 「**AI**」の範囲（生成AIを使うか、最適化ロジックか） → P-26
24. **給与目安**の計算方法 → P-27
25. **単一店舗か複数店舗か** → P-02
26. **ホスティング先・費用**（LINE Webhook には公開HTTPSが必要） → P-01
