# 店長向けマニュアル

管理画面：`https://<お店のURL>/admin`（PC・スマホどちらでも使えます）

## はじめに（最初の1回だけ）

1. **ログイン → パスワード変更**：初期パスワードのままだと、最初にパスワード変更画面が開きます。
2. **設定 → 店舗設定**：営業時間・日付の切り替え時刻・休日の曜日を確認します（初期値は 15:00〜翌5:00、朝6時で日付が変わる、土日祝が休日）。
3. **従業員 → ＋従業員を追加**：名前・ふりがな・時給（給与目安を使う場合）を登録します。
4. **iPad を打刻端末にする**：iPad の Safari で `/kiosk` を開き、共有ボタン →「ホーム画面に追加」。**ホーム画面のアイコンから開いて**「打刻端末として登録する」→ 管理者ログイン →「この端末を登録」。（ホーム画面のアプリと Safari は保存情報が別のため、必ずアイコンから開いた画面で登録してください）。登録すると、その iPad の管理者ログインは自動で解除されます。
5. **LINE 連携**：従業員の画面で「連携コードを発行」→ 6桁のコードを本人に伝え、公式アカウント「シフト管理くん」のトークに送ってもらいます。
6. **シフト → シフト枠・必要人数**：早番・遅番などの枠と、曜日ごとの必要人数を設定します。

## 毎日

- **ホーム（ダッシュボード）** を見るだけでOKです。
  - **要確認勤怠 ○件**（赤）：退勤の押し忘れ・休憩不足など。タップして修正するか、問題なければ「確認済みにする」。
  - **今日の出勤者・未打刻**：シフトの開始を過ぎても出勤していない人が赤く出ます。
  - **LINE送信失敗**：出たらタップして再送します。

## 勤怠を直すとき

**勤怠** → スタッフと月を選ぶ → 日付の出勤時刻をタップ → 時刻を直して **修正理由** を入れて保存。

- 日をまたぐ退勤は、翌日の日付で入力します（画面では「翌03:00」と表示されます）。
- 修正前の値・修正した人・理由は自動で履歴に残ります。
- 打刻がない日は「＋追加」から手入力できます。

## 毎月のシフト

| 時期 | やること |
|---|---|
| 13日 | 自動で LINE に提出依頼が届きます（何もしなくてOK） |
| 16日 | 未提出者に自動でリマインド。ホームで提出率を確認 |
| 17日 23:59 | 自動で締切。未提出の人は **シフト → ① 提出状況 → 代理入力** で電話などで聞いた内容を入力できます。締切の延長もここから |
| 18〜19日 | **② 月次条件**：今月の優先度・多め/少なめ・最大/最低日数・同じ日にしない組み合わせ・メモを入力（「前月の条件をコピー」が便利）。前月の遅刻回数などが参考に表示されますが、自動では何も変わりません |
| 18〜19日 | **③ 作成・公開 →「自動作成」**：シフト案ができます。表のマスをタップして調整。赤い数字は人数不足、上に出る「絶対条件に反する配置」も確認 |
| 20日 | **「確定して公開・通知」**：全員の LINE に確定シフトが届きます |
| 公開後 | 修正したら **「変更を公開・通知」**：変更があった人にだけ LINE が届きます |

**AI補助（設定している場合）**：② 月次条件の画面で「山田さんは今月多め、田中さんは最大8日」のように文章で書くと条件の案を作ります。反映して保存するかは店長が決めます。案を作るときは、スタッフ名・今の条件・書いた文章が Anthropic 社の AI に送信されます。

## 月末（社労士への提出）

1. **要確認** を0件にする（修正 or 確認済み）。
2. **出力** → 対象月を選ぶ → **Excel** または **CSV**。PDF が必要なら「印刷 / PDF保存」。

## 困ったとき

| こんなとき | こうする |
|---|---|
| スタッフが打刻を間違えた | 勤怠画面で修正（理由を書く） |
| iPad で打刻できない（「登録されていません」） | 設定 → 打刻端末 で登録状況を確認し、iPad で `/kiosk/setup` からもう一度登録 |
| iPad をなくした | 設定 → 打刻端末 →「登録解除」 |
| スマホをなくした | 設定 →「全端末からログアウト」→ パスワード変更 |
| スタッフが LINE を変えた | 従業員画面で「連携し直す」→ 新しいコードを送ってもらう（古いリンクは使えなくなります） |
| 管理者を増やしたい | 設定 → 管理者アカウント → 追加（仮パスワードは初回ログイン時に変更されます） |
| 他の管理者がパスワードを忘れた | 設定 → 管理者アカウント → その人の「仮パスワード再発行」 |
| 管理者が1人だけで、その人がパスワードを忘れた | 開発・保守担当に README の「管理者の復旧」の手順を依頼 |
| パスワードを変えたら他の端末でログアウトされた | 仕様です（安全のため）。他の端末では新しいパスワードでログインし直してください |
