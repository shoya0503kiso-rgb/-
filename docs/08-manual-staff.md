# スタッフのみなさんへ：打刻とシフトの使い方

## 1. 打刻（お店の iPad）

1. iPad で **自分の名前をタップ**
2. 出てきたボタンを押すだけ

| 今の状態 | 出てくるボタン |
|---|---|
| まだ出勤していない | **出勤** |
| 勤務中 | **休憩開始** / **退勤** |
| 休憩中 | **休憩終了** / **退勤** |

- 大きく「出勤しました」と出たら完了です。
- 休憩中のまま退勤を押しても大丈夫です（休憩も終わります）。ただ、できるだけ「休憩終了」を押してください。
- **出勤を押し忘れたとき**：名前をタップ →「出勤を押し忘れた → 退勤だけ記録する」で退勤だけ記録し、店長に出勤時刻を伝えてください。
- **前の日の退勤を押し忘れたとき**：店長に伝えてください。次の日はふつうに出勤を押せます。
- PIN（4桁）を設定している人は、ボタンのあとに PIN を入力します。

## 2. LINE「シフト管理くん」

最初に1回だけ：店長から **6桁の連携コード** をもらい、トークに送ってください。「連携が完了しました」と返ってきたらOKです。

メニューのボタン（または文字を送る）で使えます。

| ボタン | できること |
|---|---|
| **シフト提出** | 来月の希望シフトを出すページが開きます |
| **シフト確認** | 確定したシフトが届きます |
| **勤務時間** | 今月の勤務日数と時間が届きます |
| **給与目安** | 今月の給与のだいたいの額（交通費・控除は含みません） |

## 3. 希望シフトの出し方（毎月）

- **13日ごろ** LINE に「来月の希望シフトを提出してください」と届きます。
- **17日 23:59 まで** に提出してください（締切までは何度でも直せます）。
  1. LINE のリンクを開く
  2. 日ごとに **○（出勤できる）** か **×（出勤できない）** を押す（「全部○」「全部×」も使えます）
  3. 枠や時間の希望があれば選ぶ
  4. 下の **「提出する」** を押す
- **○を押していない日は「出勤できない」扱い**になります。
- **20日ごろ** 確定したシフトが LINE に届きます。変更があったときも LINE でお知らせします。

※ LINE のリンクはあなた専用です。他の人に送らないでください。
