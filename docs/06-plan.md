# 06. 実装計画（Phase 1〜4）と体制

## 体制（監督AI）
- **監督AI**：要件整理・設計・暫定仕様の管理・実装・テスト計画・各Phaseの受け入れ判定
- **レビューAI**：各Phase完了時に独立したレビュー担当AIがコード全体を確認し、バグ・仕様漏れを指摘 → 監督AIが修正
- 各Phaseの完了条件：型チェック・Lint・ユニットテスト・E2Eテストがすべて通り、レビュー指摘の対応が済んでいること

## 技術構成
| 区分 | 採用 |
|------|------|
| フレームワーク | Next.js 15（App Router）+ TypeScript |
| DB | Prisma（開発 SQLite／本番 PostgreSQL） |
| UI | Tailwind CSS（スマホ・iPad対応） |
| 認証 | 管理者：ID/パスワード＋署名付きCookie、打刻端末：端末トークンCookie |
| 出力 | CSV（BOM付き）、Excel（exceljs）、印刷用ページ |
| テスト | Vitest（計算・判定・生成ロジック、サービス層）、Playwright（画面E2E） |

## ディレクトリ
```
src/lib/        純粋ロジック（時刻計算・勤務時間計算・異常判定・シフト生成）※DB非依存でテスト容易
src/server/     サービス層（DBアクセス・業務処理）。画面・LINE・cron はここだけを呼ぶ
src/server/line LINE 連携（Webhook処理・送信アダプタ）
src/app/        画面とAPI
tests/          ユニット・サービステスト、e2e/
docs/           設計ドキュメント
```
