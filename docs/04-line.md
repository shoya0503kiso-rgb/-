# 04. LINE連携設計

## 構成

```
LINEアプリ ──▶ LINE Platform ──(Webhook POST /api/line/webhook)──▶ 本アプリ
                                                                   │ 署名検証(X-Line-Signature)
                                                                   ▼
                                                          LINEコマンド処理(src/server/line)
                                                                   │ 勤怠/シフトの「サービス関数」だけを呼ぶ
                                                                   ▼
業務処理（シフト公開など）──▶ Notification テーブル（アウトボックス）
                                   ▲
定期実行(cron) /api/cron/daily ────┘──▶ ディスパッチャ ──▶ LINE Push API（未設定ならモック）
```

- **疎結合**：勤怠・シフトのコードは LINE を知らない。「通知を積む」「サービス関数を呼ばれる」だけ。
  LINE 以外（メール等）への切替は送信アダプタの追加で対応できる。
- **モック送信**：`LINE_CHANNEL_ACCESS_TOKEN` 未設定時は送信せず、通知履歴に「モック送信」として記録。
  開発・デモ時に LINE なしで全フローを確認できる。

## アカウント紐付け（P-17）
1. 管理者が従業員編集画面で「LINE連携コードを発行」→ 6桁コード（有効24時間）
2. 従業員が公式アカウント「シフト管理くん」を友だち追加し、トークにコードを送信
3. Webhook でコードを照合し `LineAccount` を作成 →「○○さんの連携が完了しました」と返信
- 1従業員につき1LINEアカウント。再連携は新しいコードで上書き。

## トークのコマンド（リッチメニューから送信される想定）

| 送信テキスト | 動作 |
|-------------|------|
| 6桁数字 | アカウント紐付け |
| `シフト提出` | 受付中の期間があれば本人専用の提出リンクを返信、なければ「受付期間外」 |
| `シフト確認` | 確定済みシフト（今月・来月）をテキストで返信＋詳細リンク |
| `勤務時間` | 今月の勤務日数・実働合計を返信 |
| `給与目安` | （Phase 4）今月の給与目安を返信 |
| その他 | 使い方を返信 |

## 本人専用リンク
- `/s/[token]`（提出）, `/me/[token]`（確認）。トークンは従業員ID・用途・期限を含み、サーバ秘密鍵で署名（HMAC）。
- 有効期限：提出リンク＝締切まで、確認リンク＝7日。期限切れの場合は LINE で再度コマンドを送れば新しいリンクが届く。
- 将来 LIFF に切り替える場合も、画面とサービス関数はそのまま使える。

## 自動通知（P-19）
`/api/cron/daily` を毎日 10:00（JST）に実行（Vercel Cron 等。`Authorization: Bearer CRON_SECRET` 必須）。

| 日 | 処理 | 対象 |
|----|------|------|
| 13日（設定値） | 翌月のシフト期間を作成し受付開始、提出依頼を通知 | LINE連携済みの在籍者全員 |
| 16日（設定値） | 提出リマインド | 未提出者のみ |
| 17日 締切後の最初の実行 | 受付終了（状態を CLOSED） | — |
| 公開時（管理者操作） | 確定シフト通知 | 全員（シフト0日の人にも「今月のシフトはありません」） |
| 公開後の修正時 | 変更通知 | 変更があった人のみ |

- 通知は `dedupeKey` で一意化（例 `SHIFT_REQUEST:2026-11:{employeeId}`）しているので、cron が複数回動いても二重送信しない。
- 送信失敗は `FAILED` として記録し、次回の cron で最大3回まで再送。

## 必要な準備（店舗側）
1. LINE公式アカウント作成（名前「シフト管理くん」）→ Messaging API を有効化
2. チャネルシークレット・チャネルアクセストークンを環境変数へ設定
3. Webhook URL に `https://<本番ドメイン>/api/line/webhook` を設定
4. リッチメニュー（シフト提出／シフト確認／勤務時間）を作成
5. 料金：無料プランは月200通。スタッフ20人×月4通程度なら収まる見込み（超える場合はライトプラン）
