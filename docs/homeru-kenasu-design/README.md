## ゲームの中身（変えないもの）
読めない外国語の言葉が1つ画面に出て、それが「しょうや（主役）を褒めてる」のか「バカにしてる」のかを当てる。
1. タイトル →「スタート」
2. 10問ランダムで出題。上に「第何問 / 10」「正解数」「🔥連続正解数」と進み具合バー
3. 言葉が画面中央にドンと出る（言語名は伏せる）
4. 「👍 褒めてる」「👎 バカにしてる」の2ボタン
5. 押すと大きく ⭕ 正解！ / ❌ ざんねん！（正解は紙吹雪、不正解はカードが揺れる）
6. 答え表示：言語名・読み（カタカナ）・意味・正解。読みの横に 🔊（端末に音声があるときだけ）
7. 「次へ」（10問目は「結果を見る」）
8. 結果：正解数・称号・ひとこと・最高連続正解・10問のふりかえり・「もう一回」

## 守ってほしいこと
### 動作を壊さないために
- **`<script>` の中は基本さわらない。** 特に `WORDS` 配列（単語データ）と `RANKS`（称号）、ゲームの流れは変更しないこと
- JS が使っている **id はすべて残す**：
  `title` `game` `result` `startBtn` `qNum` `scoreNow` `streak` `bar` `wordcard` `word` `choices` `answer` `aLang` `aRead` `aMean` `aType` `nextRow` `nextBtn` `finalScore` `rank` `rankNote` `bestStreak` `review` `againBtn` `verdict` `vMark` `vLabel`
- JS が付け外しする **class 名も残す**（見た目は自由に変えてよい）：
  - `.screen` / `.on` …表示中の画面
  - `.stage` / `.answered` …答えを出したあとの状態（言葉とボタンを小さくして1画面に収めるために使っている）
  - `.choice` と `data-pick="praise"` / `data-pick="mock"`、`.dim`（選ばなかった方）、`.picked`（選んだ方）
  - `.word` / `.long`（8文字以上の長い単語）/ `.pop`（出てくるアニメ）
  - `#wordcard` の `.shake`（不正解）/ `.flash-ok`（正解）
  - `#streak` の `.hot`（3連続以上）
  - `#answer` の `.on`、`#nextRow` の `.on`
  - `#aType` の `.v.praise` / `.v.mock`（正解が褒めかけなしか）
  - `#verdict` の `.ok` / `.ng` / `.show`
  - `.confetti`（紙吹雪）、`.speak`（🔊ボタン）、ふりかえりの `.w`（単語）と `.m`（意味）
- 演出の色やアニメの中身は自由に変えてOK。ただし CSS アニメ名を変えるなら、それを使っている CSS 側もそろえる

### 外国語の文字のために
- アラビア語・タイ語・ヒンディー語・ジョージア語・ヘブライ語・アムハラ語などが出る。**Google Fonts の Noto Sans Arabic / Thai / Devanagari / Georgian / Hebrew / Ethiopic の読み込みは消さない**（消すと端末によって □ になる）
- 言葉を表示する要素の `font-family` には、上の Noto の各フォントを入れたままにする。日本語の飾りフォントに変えるなら、外国語の言葉の部分には使わない
- 言葉の要素の `dir="auto"` は残す（アラビア語・ヘブライ語は右から左）

### 見え方
- **スマホ（320〜430px）と店のテレビ（1920×1080）の両方で崩れないこと**。文字とボタンは大きめ（テレビは離れて見る）
- テレビでは、問題・答え・結果の各画面が**スクロールなしで1画面に収まる**こと
- 横スクロールが出ないこと
- 一番長い単語（`τεμπέλης`、`красавчик`、`ขี้เกียจ` など）でもカードからはみ出さないこと
- 1ファイル（HTML/CSS/JS をまとめたまま）・ビルド不要・サーバーなしで開ける、は維持
- 外部から読み込むのは Google Fonts だけにする（画像を使うなら HTML に埋め込むか CSS で描く）

## 確認方法
直したら、これでスクショとはみ出しチェックができます（Playwright が必要）。

```bash
node docs/homeru-kenasu-design/screenshot.cjs docs/homeru-kenasu-design/after
```

`after/` にスマホ・小さいスマホ・テレビの全画面のスクショが出て、最後に「問題なし」か、どこがはみ出したかが表示されます。`now/` と見比べて確認してください。
