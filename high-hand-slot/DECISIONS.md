# 決めたこと(仕様にない細部)

- アプリはリポジトリ内の `high-hand-slot/` に置く(既存のシフト管理くんとは独立した Node アプリ)。
- ポートは 3000(環境変数 `PORT` で変更可)。`/` は `/control/` へリダイレクト。
- Node.js は 22 以上(LTS)。テストは Node 標準の `node --test`(追加ライブラリ不要)。
- `data/` は git 管理外。初回起動時に初期値で自動作成する。
- JSON が壊れて読めない場合は `*.broken-日時` に退避して初期値で起動する(ログを上書きで失わないため)。
- 確率は小数第2位まで設定可(内部は 1/10000 単位の整数で `crypto.randomInt` 抽選)。
- 絵柄ごとに「演出の格(tier)」を持たせる:0=ハズレ、1=小(🍺)、2=中(⭐)、3=大(🪙)、4=大当たり(7️⃣)。tier 0 の絵柄が「ハズレ」扱い。「今月の 7️⃣ 獲得者」は tier 4 の当選者。
- ガセリーチのリーチ絵柄は景品のある絵柄から選ぶ(💀💀でリーチしても盛り上がらないため)。通常ハズレは1・2リール目を必ず別絵柄にする(リーチにも3つ揃いにもならない)。
- リール停止位置は「確率表の並び順」をリールの帯とし、その何番目で止まるかをサーバーが返す。
- ロイヤル1回目の確定絵柄は設定 `royalFirstSymbolId`(初期値 7️⃣)。その絵柄を削除したら最も格の高い当たり絵柄に自動で切り替える。
- 絵柄は2〜20個、当たり絵柄が最低1つ必要。見た目が同じ絵柄(異体字セレクタ違い含む)は重複扱い。回転数は役ごとに1〜20。
- 設定ファイルの一部が不正なら、その項目だけ初期値に戻し、元ファイルは `settings.json.broken-日時` に残す。
- `npm run simulate` で現在の設定の10万回シミュレーションを表示できる(ファイルは書き換えない)。
- 進行(告知 → 回す待ち → 回転 → 結果 → まとめ → 待機)と演出時間はサーバーが管理する。テレビが落ちたりリロードしても進行は止まらず、つなぎ直すと今の場面から表示する。
- 演出時間:告知4.5秒、リール停止 1.8/2.6/3.4秒、リーチ時は3リール目を+3.2秒、結果表示はハズレ3.5秒〜7️⃣11秒、全回転後のまとめ7秒 → 待機画面。
- 1回転ごとに「回す」を押してもらう(押すたびに盛り上がるため)。告知中に押された場合は告知を切り上げて回す。
- 結果はリールが回り出す前に確定してログに書き込む(途中で電源が落ちても記録が残る)。
- 演出の見出し:ハズレ「ざんねん…」、🍺「WIN!」、⭐「NICE WIN!!」、🪙「BIG WIN!!!」、7️⃣「JACKPOT!!!!」(画面フラッシュ+紙吹雪+長いファンファーレ)。
- 全回転後に「まとめ画面」(名前・役・全回転の結果)を出す。1回ごとの結果カードと合わせて写真用。
- テレビは 1920×1080 の固定レイアウトを画面サイズに合わせて拡大縮小する(どの解像度でも崩れない)。長い名前は文字を自動で縮める。
- ブラウザの仕様で、テレビは一度クリック(リモコンの決定)するまで音が出ない。その旨を画面右下に小さく表示し、音が出るようになったら消す。
- 待機列は `data/queue.json` にも保存し、PC を再起動しても続きから回せる(回転途中の人は次の回転から。ロイヤルの 7️⃣ 確定は付け直さない)。
- 操作画面は上から「いまの番(回すボタン)」「当選を登録」「待機列」の順。回すボタンは高さ150px以上で、押せるときだけ光る。押した瞬間に無効化し、サーバーの返事が来るまで押せない(サーバー側でも回転中・他人の番は拒否)。
- 回転中でも次の当選者の登録はできる(待機列に積まれる)。
- プレイヤー名は20文字まで、待機列は30人まで。
- 名前候補は過去の名前(新しい順、最大300件)から、入力した文字を含むものを最大8件ボタンで表示する。
- 取り消しは「まだ1回も回していない人」だけに表示し、確認ダイアログを出す。
- 画面右上に接続状態(テレビ接続中/テレビ未接続/未接続=サーバーにつながっていない)を出す。
- 対象ゲーム(トーナメント/キャッシュ)は登録時に選ばせず、操作画面に「対象ゲーム:◯◯」と表示するだけにする(ディーラーの手数を増やさないため)。
- 操作画面はサーバーとの接続が切れている間、回す・登録・取り消しを押せなくし、赤い帯で知らせる(自動でつなぎ直す)。
- 同じ名前の人がすでに待機列にいるときは、登録前に確認を出す。
- 管理画面のログインは簡易トークン(12時間有効、PC再起動で無効)。5回続けて間違えると30秒ロック。パスワードを変えると全員ログアウト。
- 設定の保存とパスワード変更は別画面(設定保存のリクエストにパスワードが混ざっても無視)。
- 景品・確率タブで、保存前の編集内容のまま「理論値チェック」できる(10万回、ログには残らない)。合計が100%でないと保存ボタンが押せない(サーバー側でも拒否)。
- 役ごとの回転数の変更は、次に登録する人から反映(登録済みの人の回転数は変えない)。
- ログ CSV は Excel で開けるよう BOM 付き UTF-8。名前の先頭が = + - @ のときは ' を付けて数式にならないようにする。月で絞り込める。
- 演出の種類の表示名は「ハズレ / 小🍺 / 中⭐ / 大🪙 / 特大7️⃣」。
- スタッフがダブルクリックで起動できるよう `start-windows.bat` / `start-mac.command` を用意(初回だけ自動で `npm install`)。
- README はスタッフ向けに「はじめに一度だけ/毎日の起動/テレビ/スマホ/当選時の流れ/管理画面/困ったとき/データ」の順で書く。
