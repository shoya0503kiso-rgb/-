# ハイハンドスロット(9High福山)

フルハウス以上でショーダウン勝ちしたお客さんが、店内テレビのスロットを回して景品を狙うためのアプリです。
店のPCで起動し、同じWi-Fiにつないだ **テレビ** と **スマホ/タブレット** のブラウザで開いて使います。
インターネットは、はじめの準備のとき以外はいりません。

| 画面 | 使う人 | 開く端末 | アドレスの最後 |
|---|---|---|---|
| テレビ画面 | お客さん全員が見る | 店内テレビ | `/tv` |
| 操作画面 | ディーラー・スタッフ | スマホ・タブレット | `/control` |
| 管理画面 | 店長 | スマホ・PC | `/admin` |

---

## 1. はじめに一度だけ(店長・PCに詳しい人向け)

1. **Node.js を入れる**
   - ブラウザで `nodejs.org` を開き、「LTS」と書かれた方をダウンロードしてインストールします(ボタンは全部「次へ」で大丈夫です)。
2. **このフォルダ(`high-hand-slot`)を店のPCの分かりやすい場所に置く**
   - 例:デスクトップ
3. **インターネットにつないだ状態で、起動ファイルを一度ダブルクリックする**(下の「2. 毎日の起動」と同じ操作)
   - 初回だけ、必要な部品を自動でダウンロードします(1〜2分)。2回目からはインターネットなしで動きます。
4. **Windows の場合:「ネットワークへのアクセスを許可しますか?」が出たら「プライベートネットワーク」にチェックして「許可」**
   - これを許可しないと、テレビやスマホからつながりません。

**起動ファイルを初めて開いたときに警告が出た場合**(2回目からは出ません)

- **Windows**:「WindowsによってPCが保護されました」と出たら、**「詳細情報」→「実行」** を押します。
- **Mac(新しいもの・macOS 15 以降)**:「開けませんでした」と出たら、いったん「完了」を押し、
  1. 画面左上の りんごマーク → **システム設定** を開く
  2. 左の一覧から **プライバシーとセキュリティ** を選ぶ
  3. 右側を下までスクロールし、「"start-mac.command"はブロックされました」の横の **このまま開く** を押す
  4. Mac のパスワードを入れ、もう一度出てくる確認で **開く** を押す
- **Mac(古いもの)**:「開発元を確認できないため開けません」と出たら、ファイルを **右クリック → 開く → 開く** の順に押します。

---

## 2. 毎日の起動(スタッフ向け)

1. 店のPCで、`high-hand-slot` フォルダを開く
2. 起動ファイルをダブルクリック
   - **Windows**:`start-windows.bat`
   - **Mac**:`start-mac.command`
3. 文字だけの画面(ターミナル。以下「黒い画面」と呼びます。Mac では白いこともあります)が開き、次のように表示されたら起動完了です

```
========================================================
  ハイハンドスロット 起動しました(9High福山)
========================================================
  テレビ      : http://192.168.1.23:3000/tv
  操作(スタッフ): http://192.168.1.23:3000/control
  管理(店長)  : http://192.168.1.23:3000/admin
```

- 数字の部分(例 `192.168.1.23`)は店のPCによって違います。**表示されたものをそのまま使ってください。**
- **黒い画面は営業中ずっと開いたままにします。** 閉じるとスロットが止まります(最小化はOK)。
- 終わるときは、黒い画面をクリックしてから `Ctrl` キーを押しながら `C`。または画面を閉じます(Windows は右上の「×」、Mac は左上の赤い丸)。

---

## 3. テレビで開く

1. テレビ(またはテレビにつないだPC・スティック端末)のブラウザを開く
2. アドレス欄に、黒い画面の **「テレビ」** の行のアドレスを入れる(例:`http://192.168.1.23:3000/tv`)
3. 全画面にする(PCのブラウザなら `F11` キー)
4. **画面を一度クリック(リモコンなら決定ボタン)する** → 効果音が鳴るようになります
   - 右下に「🔇 画面をクリック…で音が出ます」と出ている間は音が出ません。

- 待機中は、確率表・直近の当選・今月の 7️⃣ 獲得者が出ています。
- テレビの電源を切ったりページを開き直したりしても、進行はPC側で続いているので、開き直せば今の場面から表示されます。

---

## 4. スマホで操作画面を開く

1. スマホを **店と同じWi-Fi** につなぐ
2. ブラウザで、黒い画面の **「操作」** の行のアドレスを開く(例:`http://192.168.1.23:3000/control`)
3. 「ホーム画面に追加」しておくと、次からワンタップで開けます

画面右上の表示で、つながっているか分かります。

| 右上の表示 | 意味 |
|---|---|
| テレビ接続中(緑) | 準備OK |
| テレビ未接続(オレンジ) | テレビの画面が開いていません。テレビで `/tv` を開いてください |
| 未接続(赤) | 店のPCにつながっていません。Wi-Fi と、PCの黒い画面が開いているかを確認 |

---

## 5. 当選したときの流れ(ディーラー向け)

**対象:フルハウス以上でショーダウン勝ちしたとき。**
**プレイ・ザ・ボード(ボードだけで役が完成)は対象外です。**

1. **① プレイヤー名** を入れる(前に来たことがある人は、下に出る名前ボタンを押せばOK)
2. **② 役をえらぶ**(フルハウス/フォーカード/ストフラ/ロイヤル)→ 回転数は自動で決まります
3. **③ 登録してテレビに出す** を押す → テレビに「◯◯さん フルハウス!」と出ます
4. 画面上の大きな **「回す」** ボタンが光ったら、**スマホをお客さんに渡して押してもらう**
5. 回転が終わると結果がテレビに大きく出ます(写真OK)。回転数が残っていれば、もう一度「回す」
6. 全部回し終わると、まとめ画面のあと自動で待機画面に戻ります

- **その場で全回転を回します。** 持ち越し・後回しはできません。
- 回っている間は「回す」ボタンは押せません(連打しても1回分しか回りません)。
- 同時に何人も当選したら、続けて登録してください。**待機列** に入り、順番に回ります。
- **登録を間違えたとき**:下の「待機列」の **取り消し** を押します。取り消せるのは **まだ1回も回していない人だけ** です。
- ロイヤルフラッシュは **1回目が 7️⃣ 確定** です。

---

## 6. 管理画面(店長向け)

1. 黒い画面の **「管理」** の行のアドレスを開く(例:`http://192.168.1.23:3000/admin`)
2. パスワードを入れる(**最初は `9high`**。「パスワード」タブで必ず変えてください)

| タブ | できること |
|---|---|
| 景品・確率 | 絵柄・景品名・確率・演出の強さの変更、絵柄の追加/削除/並べ替え、ロイヤル1回目の確定絵柄。**確率の合計が100%のときだけ保存できます。** 保存前に「この内容で理論値チェック」で確認できます |
| ルール | 役ごとの回転数、ガセリーチ率(ハズレのうちリーチ演出にする割合)、対象ゲーム(両方/トーナメント/キャッシュ) |
| ログ | 全回転の記録(日時・名前・役・結果・景品)。月で絞り込み、**CSVダウンロード**(Excelでそのまま開けます) |
| 7️⃣獲得者 | 月ごとの 7️⃣ 獲得者一覧 |
| 理論値チェック | 今の設定で10万回まわして、実際の出現率が設定どおりか確かめます(ログには残りません) |
| パスワード | 管理画面のパスワード変更 |

- 確率や景品を保存すると、テレビの確率表にすぐ反映されます。
- 回転数の変更は、**次に登録する人から** 反映されます。
- 景品名は16文字くらいまでがおすすめです(長いとテレビの確率表の文字が小さくなります)。

---

## 7. 困ったとき

**テレビやスマホでページが開けない**
- 店のPCの黒い画面が開いているか確認(閉じていたら起動ファイルをダブルクリック)。
- スマホ・テレビが **店のPCと同じWi-Fi** につながっているか確認(ゲスト用Wi-Fiだとつながらないことがあります)。
- PCを再起動すると、アドレスの数字が変わることがあります。黒い画面に出ているアドレスを開き直してください。
- Windows で最初に「アクセスを許可」しなかった場合:スタートメニューで「ファイアウォール」と検索 →「ファイアウォールによるアプリケーションの許可」→「Node.js」の「プライベート」にチェック。
- 黒い画面に「つながらない場合は次のアドレスも試してください」と出ていたら、そちらも試してください。

**黒い画面に「ポート 3000 は使用中です」と出る**
- すでに別の黒い画面でスロットが起動しています。そちらを使ってください。

**テレビの音が出ない**
- テレビ画面を一度クリック(リモコンの決定)してください。テレビ本体の音量・消音も確認。

**回転中にPCの電源が落ちた・黒い画面を閉じてしまった**
- もう一度起動すれば、**待機列は続きから** 再開します(回し終わった分の結果はログに残っています)。
- ごくまれに、「回す」を押した瞬間に電源が落ちると、その人の回転が1回多く残ることがあります。ログを見て、回した回数を確認してください。

**操作画面に「この人の番ではありません」「回転中です」と出る**
- もう回っているか、別のスマホで操作されています。テレビの画面を見てください。

**管理画面のパスワードを忘れた**
- PCに詳しい人が、`high-hand-slot/data/settings.json` をメモ帳で開き、`"adminPassword": "…"` の部分を `"9high"` に書き換えて保存し、スロットを起動し直してください。

---

## 8. データについて

記録はすべて `high-hand-slot/data/` フォルダに入っています。**このフォルダをときどきUSBメモリなどにコピーしておくと安心です。**

| ファイル | 中身 |
|---|---|
| `settings.json` | 設定(確率・景品・回転数・パスワードなど) |
| `log.json` | 全回転の記録(消えません) |
| `players.json` | 名前の候補 |
| `queue.json` | 待機列(PC再起動後の続き用) |

- 書き込みは途中で電源が落ちても壊れない方法で行っています。
- 万一ファイルが壊れていた場合は `〜.broken-日時` という名前で残し、初期値で起動します(元の内容はそのファイルに残っています)。
- 景品は店内サービスに限ります。換金はできません(テレビ画面の下に常に表示されます)。

## 開発者向けメモ

- 必要なもの:Node.js 22 以上
- 起動:`npm start`(ポートは環境変数 `PORT` で変更可)
- テスト:`npm test`(抽選10万回の出現率 ±1%・ハズレ3つ揃い0回の確認を含む)
- 抽選のシミュレーション:`npm run simulate`(`data/settings.json` の設定で10万回。ファイルは書き換えません)
- 構成:`server.js`(起動・URL表示)/ `src/`(抽選・進行・保存・管理API)/ `public/`(テレビ・操作・管理の画面、素の HTML/CSS/JS)
- 抽選はサーバー側で `crypto.randomInt` を使って先に決め、画面のリールは結果に合わせて止めるだけです。
- 仕様は `CLAUDE.md`、仕様にない部分の決めごとは `DECISIONS.md` にあります。
